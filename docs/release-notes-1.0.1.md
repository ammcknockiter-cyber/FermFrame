## FermFrame 1.0.1

**Download `FermFrame-1.0.1.exe` below**, open it and click **Install** (or **Update** if you have 1.0.0).
Windows may say "Windows protected your PC" because the app isn't signed – click **More info → Run anyway**.

### New
- **Automatic update check.** Once a day the app asks GitHub whether there's a newer version. If there is, a bar at the
  top of the window offers **Update now**: it downloads the new version, checks it matches the published checksum,
  installs it and reopens – your FermFrames and their names are kept. Switch it off, or **Check now**, in **About**.

### Fixed
- Scrolling the Settings page with the mouse wheel while the pointer was over a drop-down changed that setting
  (for example the graph style). Drop-downs now only react to the wheel when they're open.
- More reliable secure connections to GitHub (shop list and updates).

### If you have 1.0.0
1.0.0 can't check for updates, so download this version once by hand. After that, updates come to you.
